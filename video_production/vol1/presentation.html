KEY OBJECTIVE

なぜ作図ルールが重要なのか？

DXF読込の成否は、CAD側での準備が9割を握っています。本ツールが求めるシンプルな作図ルールを守るだけで、通り芯や柱、壁が一発で完全自動認識されます。

  • ✓ 縮尺・単位の厳密な設定
  • ✓ 推奨レイヤ名による自動認識
  • ✓ ブロック解除による確実な線分抽出

RULE 01 / 04

ルール①：縮尺と単位

ESSENTIAL RULE

原寸（1:1）＆ ミリメートル（mm）

図面は必ず原寸（縮尺1分の1）、単位は「ミリメートル（mm）」で作図・書き出しを行ってください。

  • ✓ 910mmのグリッドはCAD上でも「910単位」で作図
  • ✓ ペーパー空間ではなく「モデル空間」で保存
  • ✕ 1/100や1/50等に縮小したDXFはNG
WHY IT MATTERS

ツール側での自動判定

本ツールは、図面上の座標寸法をミリメートル単位でそのまま読み込み、柱間隔（910/1000等）や壁長、床面積を精密に自動計算します。縮尺が崩れるとすべての計算に影響します。

📐
モデル空間（原寸 1:1）
1グリッド = 910mm / 1000mm 基準
RULE 02 / 04

ルール②：通り芯の作図ルール

GRID DRAWING

通り芯は「連続した1本の直線」

通り芯は途中で分断せず、端から端まで通った1本の連続直線（LINE）として作図します。線分同士の幾何交点をシステムが自動検出し、原点スナップ点として使用します。

  • ✓ 水平線・垂直線の交点が自動でターゲット交点になる
  • ✓ 点線・一点鎖線でもLINEエンティティならOK
RECOMMENDED LAYERS

推奨レイヤ名（自動認識）

以下のいずれかの名称を含めておくと、読込ウィザードで「通り芯レイヤー」として自動選択されます。

通り芯 GRID GLID 通芯 軸線

※小文字や括弧付き（例: GLID[G0], 2F_通り芯）も自動認識されます。

RULE 03 / 04

ルール③：柱の作図とレイヤ分離

PILLAR DRAWING

柱は独立したレイヤに作図

柱は通り芯や壁線とは分け、必ず「柱専用のレイヤ」に配置してください。正方形（105角・120角）または円で作図された図形を、構造計算用の柱として自動プロットします。

  • ✓ 柱の中心座標を自動検出して配置
  • ✓ 出隅（角柱）や通り芯上の柱を自動認識
RECOMMENDED LAYERS

柱の推奨レイヤ名

以下のレイヤ名にしておくことで、読込ウィザードが階層ごとの柱レイヤを自動判別します。

柱 COL COL_1F COL_2F 1F_COL 2F_COL

※壁線と同じレイヤに柱を混ぜないことが、正確な抽出のコツです。

RULE 04 / 04

ルール④：ブロック解除（分解・EXPLODE）

CRITICAL CHECK

図面のブロック化を解除して書き出す

図面全体が1つのブロックや外部参照になっていると、各線分のレイヤ情報が取得できなくなります。DXF書き出し前に必ずブロック解除（分解）を行ってください。

  • ✓ AutoCADの場合: EXPLODE コマンドで分解
  • ✓ Jw_cadの場合: 「ブロック解除」を行ってDXF保存
  • ✕ 外部参照（XREF）の未バインドはNG
DATA STRUCTURE

通常の線分（LINE）で保存

DXFの標準仕様であるENTITIESセクションに通常のLINE・LWPOLYLINEとして線分が展開されていることで、最高速度・最高精度でパースされます。

💥
EXPLODE（ブロック分解）
線分ごとのレイヤ属性を正しく維持
REAL EXAMPLE

1F.DXF LAYER MAP

1階平面図（1f.dxf）
